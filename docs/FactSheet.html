HeadEQ

A system-wide equalizer for macOS that tunes everything your Mac plays to the exact headphones you're wearing, using measured corrections, with hearing protection built in.

Signal chain

  1. Preamp (auto, clip-safe)
  2. Headphone correction
  3. 10-band graphic EQ
  4. Personal hearing correction
  5. Virtual surround
  6. Output stage
  7. Volume levelling
  8. Hearing protection
  9. Peak limiter

Dashed stages are optional features. When switched off they have no object in memory and add no work per sample. In DAC mode, a neutral chain is bypassed entirely, so audio reaches the device bit-perfect.

What it does

Sound

  • Headphone profiles from AutoEQ measurements, auto-detected from the device name
  • Add any headphone by name; edit corrections with live preview
  • Describe a preset in plain words, e.g. “EDM on Bose SoundSport, more bass”
  • Output stage: gain, balance, width, mono, swap, polarity, crossfeed, limiter
  • Virtual surround and LUFS volume levelling
  • DAC mode with per-device sample rate

Hearing

  • Sudden-loudness guard that ignores normal musical dynamics
  • Max listening level and a daily sound-dose meter
  • Per-ear hearing test with a gentle personal correction
  • macOS Background Sounds, including the tinnitus EQ pad and stop timer
  • Headphone Accommodations and AirPods Transparency settings

Tools

  • A/B switching with level matching
  • Blind preference test with a significance check
  • Import and export: .headeq, ParametricEQ.txt, GraphicEQ
  • Preset sync through iCloud Drive or any folder
  • Expert view: tuning source, target curve and filter tables for every profile

App

  • Eight color themes, Dock icon styles and a configurable menu-bar icon
  • Labelled master switch in the toolbar and menu bar
  • Launch at login and daily update checks
  • About window, searchable Help (⌘?) and a bundled User Guide

Limitations

  • Sound levels, dose and the hearing test are estimates from digital level, device volume and a sensitivity you calibrate. They are not a medical measurement.
  • Background Sounds and Headphone Accommodations controls use the same private settings as System Settings, so a future macOS update may break them. If that happens, the app falls back to System Settings.
  • Audio isn't measured or protected while the equalizer is off.
  • macOS uses one sample rate per device for all apps, so HeadEQ can't follow each track's rate automatically.
  • On iOS, an EQ can only process the app's own audio.

Specifications

Audio capture
Core Audio process tap, all apps except HeadEQ
Processing
32-bit float, no memory allocation on the audio thread
Filters
Biquads per the RBJ Audio EQ Cookbook; up to 22 correction filters plus 10 bands
Graphic EQ
32 Hz – 16 kHz, ±12 dB, Q 0.5–4, 0.5 or 0.1 dB steps
Loudness
ITU-R BS.1770-4 K-weighting; target −24 to −10 LUFS
Surround
Woodworth ITD (≈ 0.26 ms at ±30°), head shadow, 4 early reflections
Hearing dose
NIOSH: 85 dB for 8 h, 3 dB exchange rate
Hearing test
250 Hz – 8 kHz, 7 points per ear, staircase method
Sample rates
Whatever the device supports (44.1 – 384 kHz)
Permissions
System audio recording; Apple Events (alert volume only)
